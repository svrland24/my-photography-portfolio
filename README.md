# 📸 ShojolGraphy - Free High-Resolution Stock Photos & Visual Art

একটি অতি-আধুনিক, Pexels-অনুপ্রাণিত **ShojolGraphy ফটোগ্রাফি পোর্টফোলিও ওয়েবসাইট** ও **সিকিউর অ্যাডমিন প্যানেল**। এটি সরাসরি **Supabase Cloud Database**-এর সাথে যুক্ত এবং **Vercel / GitHub**-এ ১০০% শূন্য-এরর (Zero Deployment Error) সহ ১-ক্লিকে লাইভ হোস্ট করার জন্য তৈরি।

> **Domain:** `https://shojolgraphy.vercel.app`
> **Tech Stack:** HTML5 | Modern CSS3 (Pexels Design System) | ES6+ JavaScript | Supabase Cloud Client | Vercel Native

---

## ⚡ প্রধান ফিচারসমূহ (Key Features)

1. **🎨 পাবলিক পোর্টফোলিও ওয়েবসাইট (`index.html`)**:
   - **ShojolGraphy Brand**: ব্র্যান্ড নাম ও লোগো।
   - **Pexels Floating Search Bar**: ফ্লোটিং সার্চ বার এবং ট্রেন্ডিং ট্যাগস।
   - **Pexels Masonry Photo Grid**: ৩-কলাম মেসনারি গ্রিড লেআউট।
   - **Hover Overlays**: ফটোগ্রাফার ব্যাজ, লাইক ❤️ বাটন এবং ডিরেক্ট ডাউনলোড ⬇️ বাটন।
   - **EXIF Lightbox Modal**: ক্লিকে বড় সাইজে ছবি দেখার পাশাপাশি সম্পূর্ণ **EXIF Camera Specs**।
   - **Dark / Light Mode**: থিম সুইচ করার সুবিধা।

2. **🔐 অ্যাডমিন প্যানেল (ShojolGraphy Creator Portal)**:
   - **Passcode Protected**: ডিফল্ট PIN: **`admin123`**
   - **Photo Uploader**: পিসি থেকে বা লিঙ্ক দিয়ে ক্যামেরা EXIF মেটাডাটা সহ ছবি আপলোড করা।
   - **Category Manager**: নতুন ক্যাটাগরি যোগ বা মুছে ফেলার সুযোগ।
